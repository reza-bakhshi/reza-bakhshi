# Embedded Systems Engineer

I develop firmware, design PCBs, and bring up embedded Linux boards. I also build tools for probing digital interfaces, capturing signals, and inspecting serial data.

## Featured project

### RB-Pirate

A bench tool for debugging embedded hardware over I²C, SPI, and UART. The RP2350B board pairs buffered I/O and programmable target power with firmware for interactive bus commands and logic capture.

[Hardware design](https://github.com/reza-bakhshi/RB-Pirate) · [Firmware](https://github.com/reza-bakhshi/RB-Pirate-Firmware)
